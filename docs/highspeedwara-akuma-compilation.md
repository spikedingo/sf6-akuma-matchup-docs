## 一、立回基础：微步行与小技体系

**来源：** X 推文（84k+ 浏览），参考 Tokido / Leshar / Blaz 的豪鬼

### 核心观点

1. **微步行（微歩き）+ 小技置き/差し** 是地上战细分的核心，比「大步前进 + 大技」更不易事故。
2. **立小P / 立小K 的置き** 能抑制对手差し，减少被差し返し次数，保护 D 槽。
3. **小K 差し返し** 优于大足差し返し：miss 后对手误认空振而挥中足，反而变成机会。
4. **步行小K/小P** 自然引入微步行，增加观察对手弹/后撤的时间。

### 差し返し数据化方法

**来源：** X 推文（28k+ 浏览）

对舞/春丽 **立中P 置き** 的差し返し所需反应帧（训练模式验证）：

| 豪鬼技 | 反应所需帧 | 评价 |
|--------|-----------|------|
| 大足 2HK | 21F | 风险回报比偏低 |
| 中足 2MK | 17F | 难以及时 |
| 屈小P 2LP | 21F | — |
| 屈中P 2MP | 20F | **推荐**：比大足更优 |
| 立小K 5LK | 20F | 立状态空振可见时可用 |

**结论：** 不要手癖中足/大足差し返し；按距离选 **屈中P** 或 **立小K**。

## 二、春丽对局（Leshar vs Seiya 分析）

**来源：** X 视频帖 + [Zamantika 镜像摘要](https://zamantika.com/profile/highspeedwara)

### 立回距离

- 春丽战 **不必过度依赖波動**；Leshar 以差し合い为主竞争。
- 中距：立小K 先端当て vs 春丽立小P 是核心按钮。

### 优势拳脚

| 豪鬼技 | 用途 | 原因 |
|--------|------|------|
| **立小K 5LK** | 差し / 差し返し vs 立小P | 与春丽立小P 判定相性好；春丽立小P 打中后难接中足 |
| **屈中P 2MP** | vs 6MP / 4MP | 比大足/中足更现实 |
| **立小P / 屈小P** | 立中P 格挡后暴れ | 最速或延迟屈中P |
| **屈中P 先端** | シミー延迟 | 防 fuzzy、投抜、无敌 |

### 具体对策

1. **春丽立小P → 豪鬼立小K/立中K 差し返し**：春丽后续中足难接 → 观察空振再 puni。
2. **Serenity Stream（气功构）**：
   - 屈中P/中足 > 强気功：确认后 **Just Parry**。
   - 构派生：混 **立小K / 中足** 打断。
3. **立中P 格挡后**：
   - 立中P > 立小P > 中足 会被暴れ打穿 → 但 **立小P 格挡后可打返**。
   - 立中P > 微步立中P → **后撤攻击** 差し返し；立中P > 立小P 则格挡。
   - 立中P > 中足（防后撤）→ **最速暴れ** 有效。

### 防御参考（Leshar 式细撤）

**来源：** [格上を目指す防御力｜レシャーさんに学ぶ「細かく下がる」守り方](https://note.com/highspeedwara/n/n19a8fd54fb28)

- 春丽立小P 格挡 → 屈防 → 后撤 → 再屈防：分散中足风险，成功拉远距离。
- 「守る距离」与「逃げる距离」分开：中足射程外则 **一口气后撤** 而非反复屈防。

## 六、后撤空振风险与固め/打返

**来源：** note 免费文 [後ろ歩きにスカされると危険](https://note.com/highspeedwara/n/n7493ac830c03)（2026年5月）

### 进攻方（豪鬼固め）

| 连段 | 适用 | 说明 |
|------|------|------|
| DR中P > 角落后撤大P | **端限定** | 后撤/背步 → 格挡而非空振 |
| DR中P > 稍撤屈小P | 通用 | 硬直短，不易被差し返し |
| シミー后撤大P 先端 | Ken/Ryu/AKI/Juri/Viper | 后撤慢 + fuzzy 短 → 大P 先端有效 |
| 见投抜后押键 | 通用 | 9F 以内技更易 |
| 见后撤中足 | DR中P 后 | 低回报低风险 |
| **微后撤 4-7F > 6大P** | 打返 | 同时防后撤空振与小K 置き |

### 被起攻方（对手 vs 豪鬼）

- 豪鬼 DR中P 后：5F 内延迟屈小P 不空振
- 豪鬼 DR6大P 后：10F 内延迟屈小P 不空振
- 豪鬼端投 > 前step后撤：豪鬼自身 4F 内；Ryu/Ken 仅 **2F** fuzzy 屈小P

### 豪鬼打返被读

- Ryu/Ken：**大P 格挡 > 小K 置き** 专克豪鬼中足打返
- 对策：**微后撤 6大P**（同 Terry/Ken/Cammy/Rashid/Viper 思路）

## 八、波動与 Just Parry

**来源：** note [ジャスパラッシュ仕込み解説](https://note.com/highspeedwara/n/ne23c8b7595cb)、[打撃に対するジャスパの考え方②](https://note.com/highspeedwara/n/n7bbca3a6add6)

### ジャスパラッシュ仕込み（对豪鬼/对手波動均适用）

- 近距见强波動：**MP+MK 按住 > 5656+LP**
  - 强波動 → JP → DR小P PC
  - 弱波動 → 普通 parry（安全）
- 防 Ryu 弱波掌 feint：同上输入，空振则 DR小P PC

### 见取消 JP

- 中足 > 中迅雷 / 中P > TC 等 **cancel 可见后** 再按 JP
- 反应 JP 约需 **18F** 窗口

# 版本环境说明

本文档集基于以下两个补丁环境编写。涉及数值变更处，两份文档会分别标注适用版本。

## Season 3 补丁（2025年6月3日）

**来源：** [EventHubs S3 Patch Notes](https://www.eventhubs.com/news/2025/jun/03/street-fighter-s3-patch-notes/)

### 豪鬼关键改动

| 改动 | 影响 |
|------|------|
| 6HP / 波動 / 強 Adamant Flame 格挡推距减少 | 对手更容易 puni 豪鬼的 blockstring；DR 6HP 后距离变近（部分场景为 buff） |
| 2HK 空中 knockdown 时间缩短 | **取消** sweep > tatsu 双 dash 起攻、角落 safe jump 等经典套路 |
| OD 百鬼 → SA1 取消 | 角落连段选择增加 |
| 2LK 快速取消加速 |  clash 与后续命中改善 |
| 斬空波 / 百鬼 dive kick 初始 scaling 提高 | 空战收益下降，需更精准择 |
| 满蓄波動 Drive Parry 时对手 D 槽恢复 4000→5000 | 角落满蓄波動压制时对手更容易恢复 D 槽 |

### 对局思路变化

- **Sweep 起攻价值下降**：不再依赖 2HK hard knockdown 的 safe jump / 双 dash 固め。
- **DR 6HP 持续重ね** 成为更高期待值起攻手段（highspeedwara 重点推广）。
- **满蓄波動** 在 S3 仍偏弱，2026年3月补丁大幅 buff（见下）。

## 2026年3月平衡补丁（Alex 更新同期）

**来源：** [EventHubs Alex Patch Notes](https://www.eventhubs.com/news/2026/mar/16/street-fighter-alex-patch-notes/)

### 豪鬼关键改动

| 改动 | 影响 |
|------|------|
| **满蓄 Gou Hadoken 大幅 buff** | 出招更快、recovery 更短、格挡优势 +5→+20、命中数 3→4 | 中立与角落压制新核心工具 |
| **OD Adamant Flame 不再从 2MK 命中连段** | 随机 low poke 换大回报路线被砍；需更精确的确认 |
| 2HP PC/DR 后可接满蓄 OD 波動 | 远距离 puni 新连段 |
| 中 Tatsu 第二段 active 延长 | 配合满蓄波動 juggle 更稳定 |
| 214P~6P 格挡不可 puni（部分场景） | Adamant Flame 系列更安全 |

### 对局思路变化

- **满蓄波動** 成为立回与角落二选一的重要筹码；对手必须 respect。
- **2MK > OD 214P** 随机 low 路线移除，改用 2MK > 236LP 或确认后 DR。
- **满蓄波動 + 中 Tatsu** 可构成新的 corner carry 路线。
